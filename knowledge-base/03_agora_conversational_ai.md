# Agora — Conversational AI Engine

## Product purpose
Agora Conversational AI Engine is positioned as infrastructure for building and deploying real-time voice AI agents.

## Key capabilities stated by Agora
- Connect AI agents with different LLMs
- Choose ASR and TTS models
- Real-time voice conversations
- Intelligent interruption handling
- Background noise suppression
- Echo cancellation
- Selective attention / primary speaker tracking
- Interactive AI avatars
- Global real-time network infrastructure
- Real-time session monitoring and metrics

## Latency positioning
Agora states that its Conversational AI platform is designed for ultra-low-latency conversations and says response times can be up to 3x faster than voice mode from major LLMs. Treat this as an Agora marketing claim, not as a guaranteed performance for every workload.

## Integration
Agora's current product page describes a three-step integration concept:
1. Activate Conversational AI Engine.
2. Integrate Agora Edge Chip for supported hardware scenarios.
3. Deploy AI voice agents.

For a web application, follow the current official developer documentation for the exact implementation path.

## Sales use cases
Potential customer use cases supported by Agora's positioning include:
- AI voice agents
- Customer support
- Education / tutoring
- Interactive experiences
- Voice-enabled applications
- IoT / smart devices
- AI avatars

## Objection handling
If a customer asks whether Agora forces them to use one specific LLM, explain that Agora currently positions the Conversational AI Engine as supporting connections to different AI models/LLMs.

Do not promise support for a particular model or integration without verifying current documentation.
