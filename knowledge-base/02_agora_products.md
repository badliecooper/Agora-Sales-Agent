# Agora — Product Portfolio

## Conversational AI
Agora's current product portfolio includes:
- Agora Agent Studio
- Agora Conversational AI Engine
- Agora Convo AI Device Kit
- OSS: TEN

### Conversational AI Engine
Agora describes the Conversational AI Engine as infrastructure for building real-time voice AI agents with flexible connections to LLMs, ASR and TTS.

Capabilities highlighted by Agora:
- Connect different AI models / LLMs
- ASR and TTS selection
- Real-time voice interaction
- Intelligent interruption handling
- Background noise suppression
- Echo cancellation
- Selective attention
- Interactive AI avatars
- Real-time monitoring

### Agent Studio
Agora positions Agent Studio as a no-code UI for deploying and orchestrating voice AI agents.

## Real-Time Communications
Agora's product portfolio includes:
- Agora RTC

- Agora Chat

### Agora RTC
Agora RTC provides real-time voice and video communication.

Officially highlighted capabilities include:
- HD voice and video
- Adaptive bitrate optimization
- Network resilience
- AI audio/video enhancement
- Recording and AI integrations
- Interactive live streaming
- Cross-platform SDKs
