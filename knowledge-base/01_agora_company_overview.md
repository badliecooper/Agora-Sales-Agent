# Agora — Company Overview

## Source status
This document summarizes information from Agora's official website. Verify time-sensitive claims against the current Agora website before production use.

## Company / platform
Agora provides a Real-Time Engagement platform for building real-time voice, video, chat, streaming, collaboration and conversational AI experiences.

Agora describes its platform as supporting real-time engagement across voice and video, with SDKs, APIs and tools for developers.

## Platform positioning
Core positioning:
- Real-time voice and video communication
- Interactive live streaming
- Conversational AI / AI voice agents
- Chat and signaling
- Media services
- AI-powered extensions
- Analytics and real-time quality monitoring

## Developer positioning
Agora emphasizes flexible APIs and SDKs, global real-time infrastructure, low-latency communication and cross-platform development.

## Compliance / security
Agora's official Conversational AI page states that Agora is certified to ISO/IEC 27001, 27017, 27018 and 27701 and SOC 2, and lists GDPR, CCPA, COPPA and HIPAA among supported compliance/privacy standards.

## Sales positioning
For a sales conversation, position Agora as infrastructure that helps developers add real-time communication and AI interaction into applications rather than as a single-purpose chatbot product.
